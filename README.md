# US Economic Analysis Dashboard | PowerBI
## Overview
This is a personal data analytics project built to show key U.S. economic indicators using Power BI. The Dashboard transforms publicy available economic data into interactive visualizations to observe and identify trends and relationships between mahor macroecnomic indicators.

## Features
- Interactive KPI cards
- GDP, CPI, and Unemployment analysis
- Interest rate trends
- Time visualizations
- Filters and Slicers


## Objectives
- Analyze the performance of the U.S. Economy.
- Create an interactive dashboad using PowerBI.
- Present economic insights through data modeling, Power Query, and Dax

## Data Source
Federal Reserve Economic Data

## Tools 
- Power BI
- Power Query
- DAX
- Microsoft Excel
